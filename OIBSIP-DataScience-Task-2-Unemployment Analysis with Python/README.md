# Unemployment Analysis in India

## 📌 Project Overview

This project analyzes unemployment trends in India using Python and data visualization techniques. The goal is to explore unemployment rates, employment levels, and labour participation across different regions, dates, and areas.

This project was completed as part of the **Oasis Infobyte Data Science Internship — Task 2**.

## 🎯 Objectives

* Analyze unemployment rates across different regions.
* Study employment and labour participation levels.
* Compare unemployment trends over time.
* Explore differences between rural and urban areas.
* Identify patterns and insights using data visualization.

## 📂 Dataset

**Dataset:** Unemployment in India

The dataset contains **768 records and 7 columns**.

### Features

| Column                                    | Description                         |
| ----------------------------------------- | ----------------------------------- |
| `Region`                                  | Name of the Indian state or region  |
| `Date`                                    | Date of the observation             |
| `Frequency`                               | Frequency of data collection        |
| `Estimated Unemployment Rate (%)`         | Estimated unemployment rate         |
| `Estimated Employed`                      | Estimated number of employed people |
| `Estimated Labour Participation Rate (%)` | Estimated labour participation rate |
| `Area`                                    | Rural or Urban area                 |
