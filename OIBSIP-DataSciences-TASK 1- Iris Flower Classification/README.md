# Iris Flower Classification 🌸

## 📌 Project Overview

This project focuses on classifying Iris flowers into different species using Machine Learning.

The Iris dataset contains measurements of flower features, and the goal is to build a classification model that predicts the species of an Iris flower based on these measurements.

This project was developed as part of my learning journey in **Machine Learning and Data Science**.

## 🎯 Objectives

* Understand the Iris dataset.
* Perform Exploratory Data Analysis (EDA).
* Visualize relationships between flower features.
* Prepare the data for Machine Learning.
* Train a classification model.
* Evaluate the model's performance.
* Predict Iris flower species.

## 📂 Dataset

The project uses the **Iris Flower Dataset**.

### Features

| Feature      | Description         |
| ------------ | ------------------- |
| Sepal Length | Length of the sepal |
| Sepal Width  | Width of the sepal  |
| Petal Length | Length of the petal |
| Petal Width  | Width of the petal  |

### Target Variable

The target variable is the **Iris species**:

* Setosa
* Versicolor
* Virginica
